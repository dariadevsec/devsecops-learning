### Команды, которые я выучила

| Команда | Что делает |
| --- | --- |
| `pwd` | показывает, в какой папке я сейчас |
| `ls` | показывает, что лежит в папке |
| `ls -a` | показывает ещё и скрытые файлы (имя начинается с точки) |
| `cd папка` | заходит в папку |
| `cd ..` | выходит на уровень выше (пробел обязателен) |
| `mkdir имя` | создаёт папку |
| `cat файл` | показывает, что написано в файле |
| `file файл` | определяет тип файла (текст или данные) |
| `find` | ищет файлы по условиям (размер, владелец, тип) |
| `grep слово файл` | находит строки со словом |
| `sort` и `uniq -u` | сортирует строки и оставляет те, что встречаются один раз |
| `strings файл` | вытаскивает из файла читаемый текст |
| `base64 -d файл` | расшифровывает запись base64 |
| `ssh` | подключает к другому компьютеру через интернет |
| `exit` | выходит из подключения |

### Что я поняла
- Символ `\|` («труба») передаёт результат одной команды в другую
- Пробелы в имени файла нужно брать в кавычки
- Имя файла, которое начинается с дефиса, пишут с `./` перед ним
- Команда `2>/dev/null` прячет сообщения об ошибках
- Base64 это не защита, а просто другая запись текста

### Где я ошиблась
- Написала `cd..` без пробела и получила `command not found`
- Пыталась подключиться к следующему уровню, не выйдя из предыдущего
- Не знала, что в терминале копируют через Ctrl+Shift+C
